# E01 · 两岗位版本与可用 PDF

状态：草案，未执行。Growth Manager 负责设计与推荐；Codex 只执行另行批准的修复。

假设：已有经历的人能独立把一份基础简历做成两个岗位版本，保留原稿，并得到内容真实、排版可用的 PDF。依据和未知见[市场审计](../reports/folio-growth-audit.md)。

步骤建议：先用明确标记的虚构经历和两个虚构 JD 做内部检查；确认原稿保留、版本可区分、事实无新增、实际 PDF 可打开且分页可读、JSON 可备份。真实登录和模型调用的验证范围另批；不上传真实简历。

若 G1/G2/G3 通过，提议研究 8 人，两个经历阶段各 4 人。没有既有用户群时先准备低接触说明和自助反馈草稿，不能擅自发招募或联系。记录既有替代品、完成时间、协助次数、失败步骤和第二版本复用；不记录个人身份或简历原文到本仓库。

候选主指标：无协助且用户确认事实真实、PDF 可用的完成数／有效参与者数。基线待建立，目标与样本待审批。建议门槛 ≥6/8 且无严重内容丢失／隐私风险，再评估获客；这是内部方向规则，不是统计显著性保证。失败则报告摩擦并提修复，未满样本则证据不足。打印按钮触发不算可用 PDF。

观察周期、研究工具、预算、补偿、对象和同意方式待批准。出现无依据事实、隐私风险或越权立即暂停，撤回未发布材料并报告。结果：未执行。

审批关联：[D02、D03、D04、D05](../reports/decisions.md)。未经批准不启动研究、发布、工程或支出。

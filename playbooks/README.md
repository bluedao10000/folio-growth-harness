# 工作手册

## 公开研究

1. 明确问题和决策编号，优先官方公开来源。
2. 记录 URL、日期和适用市场；产品源码固定 cn 提交。
3. 区分页面承诺、代码可见实现和生产验证；记录反例及未知。
4. 只摘录完成判断必需的信息，不存个人信息或敏感配置。
5. 将结果放入 reports，更新策略与实验卡中的假设。

## 提案到执行

1. Growth Manager 填 [实验模板](../experiments/template.md)。
2. 检查 [审批门](../OPERATING_RULES.md)，将具体问题列入决策清单。
3. 所有者批准具体范围；额外对外行动独立批准。
4. Codex 接受获批工程任务才实施，本轮保持文档交付。
5. 对照 [验收](../evals/acceptance.md)，记录未完成验证和停止原因。

## 每周复盘

用 [周报](../reports/weekly-template.md) 同时写支持与反对证据，区分工作产出与业务结果。没有执行实验就写“未执行”。建议继续／调整／停止必须说明依据和下一步批准事项。

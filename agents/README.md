# 角色与交接

| 角色 | 负责 | 不能自行决定 |
| --- | --- | --- |
| Growth Manager | 用户问题假设、公开研究、证据质量、实验设计、推荐优先级、复盘 | 工程上线、发布、联系用户、广告支出、合并 |
| Codex | 执行明确获批的工程任务；本轮只维护文档、分支与草稿 PR、校验交付 | 替代产品／增长决策，扩大授权范围 |
| 所有者 | 主张、数据、实验、工程、发布与预算的逐项批准 | 以沉默视为批准 |

交接包：问题 → 证据 URL → 假设 → 方案 → 范围／非目标 → 风险 → 验收 → 回滚 → 决策编号。未获批的工程想法只写进 [决策清单](../reports/decisions.md)。
